# OBS 数据处理工具 (OBS Data Processing Tool)

一款面向水文与河口海岸野外观测的本地桌面数据处理工具。用于读取 OBS 浊度仪原始观测文件（`.dat`），按目标整点与垂向分层规则筛选代表性观测记录，自动导出标准 `.csv` 成果表格，并提供交互式**深度-时间剖面过程线核查**、**采样来源行号追溯**以及**单文件仪器时间平移校正**功能。

项目目前处于开发阶段，主要面向 Windows 10 / 11（64 位）桌面环境。当前功能与待验收事项见 [ROADMAP](docs/ROADMAP.md)。

## 核心功能概览

1. **动态传感器表头识别与多文件测点归并**
   - 自动按每份 `.dat` 文件顶部的 `Sensor Data Columns` 声明独立识别深度（Depth）、浊度（OBS-1）、温度（Temperature）、盐度（Salinity）及可选的电导率/电池电压列，兼容 UTF-8（含 BOM）与 GB18030 编码。
   - 自动按文件名前缀（`#` 号之前的部分）归并同一测点的多份连续或断电续测文件，自动过滤仪器导出尾注与全零结束标记行。
2. **参考水深智能推算与人工确认门禁**
   - 对未手动填写水深的测点，后台基于多段有效下放剖面峰值自动推算参考水深 $H$，并评估剖面数量、峰值四分位距（IQR）与同秒冲突。
   - 当推算可信度较低或观测不足时，在处理前自动弹出**水深填写与确认**窗口集中把关，避免静默使用不可靠水深导出结果。
3. **灵活的垂向分层方案与整点匹配**
   - 内置随水深自动切换的 1 / 2 / 3 / 5 / 6 层系统标准规则，支持单点或批量锁定固定系统层数，并提供可视化的**自定义相对层位规则库**（`0 ~ 1` 比例，持久化保存）。
   - 严格保持原始实测数值（不插值、不平滑、不平均、缺测留空不补 0），自动标记**缺少匹配片段**、**缺层**、**片段复用**、**跨层复用**与**深度偏差超限**。
4. **交互式过程线与采样溯源核查**
   - 内置自绘深度-时间剖面画布（支持滚轮缩放、水平滚动、目标整点一键定位与恢复全图），直观区分匹配片段、邻近背景、各层选中点与片段最深峰值。
   - 逐层展示目标深度、实测深度、带符号偏差、精确到物理行号的来源文件路径及共用片段/跨层共用明细。
5. **实用工具：单文件 DAT 时间校正四步向导**
   - 针对外业施测时仪器内部时钟未校准的场景，支持**已知时间对应关系**与**按抛测规律匹配（自动整理局部下放候选与完整抛测动作）**两种全局时间平移方案。
   - 严格遵循“前 3 步纯只读预览 → 第 4 步显式确认写入 → 原位修改前自动生成不覆盖的 `.bak` 完整原始备份 → 写后复验与失败回滚 / 原生另存”的数据安全流程。

## 下载与运行

- **发行状态**：开源版本暂未发布二进制程序。请按[开发指南](docs/DEVELOPMENT.md)安装锁定依赖后运行源码；未来交付以本仓库 Releases 为准。
- **源码开发模式启动**（已按开发指南配置 `.venv-obs-release` 环境）：
  双击仓库根目录下的 `启动开发版.cmd`，或在 PowerShell 7 中执行：

```powershell
# 启动桌面图形界面
pwsh -File scripts/dev.ps1 gui

# 运行合成数据自动化回归测试套件
pwsh -File scripts/dev.ps1 test
```

## 仓库架构与代码导读

本项目采用 **“纯标准库算法核心 + PySide6 桌面视图层 + 独立子进程任务隔离”** 的分层架构，方便人类开发者阅读、测试与维护：

```text
obs-tool-oss/
├── src/obs_tool/              # 现行应用程序源码包
│   ├── data_types.py          # 全链路字典结构 TypedDict 契约（供 IDE 自动补全与类型阅读）
│   ├── models.py              # 核心配置数据类（Point、Rules、Batch）与参数合法性校验
│   ├── input_policy.py        # 外部输入零信任边界、容量预算（InputLimits）与流式有界读取
│   ├── readers.py             # OBS .dat 动态表头解析、尾注识别、去重与同秒冲突检测
│   ├── algorithm.py           # 观测片段切分（前后缓冲）、整点峰值匹配与垂向各层选点核心算法
│   ├── processing.py          # 单测点目标整点序列生成、选点状态汇总与深度容差判定
│   ├── depth.py               # 基于受支持下放剖面峰值的参考水深 H 自动推算算法
│   ├── depth_workflow.py      # 批处理前的水深估算编排与需人工确认判据
│   ├── correction_actions.py  # 时间校正专用：局部包络下放候选提取与完整抛测动作连续性合并
│   ├── time_correction.py     # 单文件时间校正分析、首尾缺测分配、.bak 原子备份与写回校验
│   ├── exporters.py           # CSV 成果表导出、Windows 文件锁重试原子写入与预检
│   ├── runner.py              # 批处理输出目录保护、逐测点错误隔离与内部追溯记录落盘
│   ├── result_projection.py   # 结果核查页只读显示投影（反向索引片段复用/跨层复用与 HTML 报告）
│   ├── curve_context.py       # 深度-时间过程线快照流式保存、四点包络降采样与默认视野计算
│   ├── desktop.py             # 主窗口控制器（Window）：协调草稿编辑、后台任务状态机与结果快照
│   ├── workspace_view.py      # 主窗口“数据与设置”及“处理结果”双页签布局装配
│   ├── result_view.py         # 结果核查视图：状态/指标筛选表、各层采样表与来源详情面板
│   ├── curve_canvas.py        # 自绘交互式深度-时间剖面画布（Curve）与时间校正预览画布
│   ├── dialogs.py             # 单测点编辑（PointDialog）、文件关联与高级设置（AdvancedDialog）
│   ├── bulk_dialog.py         # 多选测点原子批量设置对话框（BulkDialog）
│   ├── tools_dialog.py        # 实用工具列表与单文件时间校正四步向导（ToolsDialog）
│   └── ...                    # 后台子进程入口、Windows 原生文件对话框隔离及主题样式模块
├── tests/                     # 基于合成观测数据的可重复单元测试与 Qt 交互回归套件
├── scripts/                   # 开发启动（dev.ps1）、Nuitka 构建（build.ps1）与发行验收脚本
└── docs/                      # 技术文档与第三方许可资料
```
