【软件功能与基本操作流程】
本软件用于 OBS 浊度仪原始观测数据（.dat 文件）的整点匹配、垂向分层筛选与成果表格（.csv 文件）导出，并提供过程线浏览、异常复核及单文件记录时间校正功能。

• 标准作业流程：
  导入 DAT 原始数据（若仪器记录时间有偏差，可先通过右上角“实用工具 → 时间校正”校准） → 单点或批量配置参考水深 H、垂向分层规则与目标起止时间 → 确认 CSV 保存位置 → 点击“开始处理并导出 CSV”（按需在弹窗中核实水深） → 在“处理结果”页结合过程线与采样明细核查数据质量并打开 CSV 结果文件夹
• 原始数据安全原则：
  常规数据导入、参数调整与筛选导出全程仅读取原始 DAT 文件，不对原始文件作任何修改；生成的 CSV 表格自动存入独立的新建文件夹。唯一会修改 DAT 文件的情形是使用右上角“实用工具 → 时间校正”并在第 4 步主动点击“确认修改”（写入前软件会自动生成完整的 .bak 原始备份文件）。

一、数据导入、文件要求与测点管理
1. 原始数据格式与传感器通道要求：
   • 软件支持包含标准传感器声明表头（Sensor Data Columns，且数据列为单列 Mean 平均值格式）的文本型 DAT 文件，自动识别 UTF-8 与中文 GB18030 编码。
   • 每份 DAT 文件须同时包含四项基本观测通道：深度（Depth，单位 m）、浊度（OBS-1，单位 NTU）、温度（Temperature，单位 °C）、盐度（Salinity，单位 PSU）。电导率（Conductivity）与电池电压（Battery）属于可选通道，缺失不影响数据读取；最终结果表与导出的 CSV 表格主要针对深度、温度、盐度、浊度四项指标。
   • 软件按每份文件各自的表头顺序独立识别对应列，同一测点下不同文件即使列顺序不同也可正常合并处理。但同一测点所关联的文件将作为完整集合进行校验：若其中任一文件缺少表头、缺少上述四项必需通道或存在严重格式损坏，为避免在不完整数据上导出残缺结果，该测点将整体停止导出并报错提示具体故障文件，其余正常测点继续处理。
   • 仪器导出的文件末尾若带有统计信息或命令提示（如“Bytes read from file.”、“File ended without EOF.”、“OBS>”以及文件最末尾全零的 1970/1969 结束标记行），软件会自动识别并予以剔除，不计入有效观测。注意：“File ended without EOF.”代表仪器记录非正常结束，软件仅能读取文件中已实际存盘的观测记录，无法恢复断电前未写入仪器的缺失数据。
   • 软件对常规连续观测时长、采样频率或断电续测次数不设硬性限制；但若单份文件体积过大或整批累计数据量超出软件安全处理上限，系统将提前拒绝并提示缩小单次导入的数据范围。
2. 导入数据方式（主界面“数据与设置”页）：
   • 添加文件夹：选择一个文件夹，将该文件夹当前层级下的全部 DAT 文件加入测点列表（不会自动向下扫描子文件夹）。
   • 添加 DAT 文件：每次手动选择一个或多个 DAT 文件，支持跨文件夹分批反复追加。
3. 测点编号提取与自动合并规则：
   • 软件自动取文件名（不含扩展名）中第一个“#”号之前的内容作为“测点编号”。例如“1-1#.dat”、“1-1#第一次.dat”、“1-1#第二次.dat”均自动归入测点“1-1”；若文件名中不含“#”号，则以完整文件名作为测点编号。
   • 追加文件时，若新文件的测点编号与列表中已有测点完全一致，将自动并入该测点（同一路径的文件不会重复加入；来自不同文件夹的同编号文件也会合并，导入后请核对“数据文件”列的归属情况）。
   • 由于 Windows 文件系统不区分大小写，若新导入或修改后的编号与已有测点仅存在大小写差异（如“S1”与“s1”），系统会提示编号冲突并拒绝操作，请先统一文件名或修改测点编号。
   • 测点编号仅允许使用汉字、字母、数字、下划线（_）和短横线（-），不得包含空格或路径分隔符，也不得使用系统保留名称（如 CON、NUL、COM1 等）。在软件内修改测点编号仅改变导出文件名与显示标识，不会重命名电脑硬盘上的原始 DAT 文件。
4. 关联文件调整、列表移除与批次清空：
   • 设置数据文件：在列表中单击选中某个测点后点击“设置数据文件”，可查看该测点当前关联的全部 DAT 文件路径，并可单独为其“添加DAT”或选中后“移除选中文件”（按住 Ctrl 或 Shift 可多选；通过此窗口添加的文件将直接归入当前测点，不再按文件名前缀拆分）。当已有测点关联的文件清单发生变动时，原本人工填写的水深会予以保留，而原本依赖自动推算的水深将重置为“处理时自动估算”，以便下次处理时基于最新文件清单重新推算。若将某测点下的文件全部移除，须重新添加文件或将该测点移出列表后方可开始整批处理。
   • 移除勾选测点：点击“更多 → 移除勾选测点（不删除文件）”，仅将首列复选框已勾选的测点从当前软件列表中移除。
   • 开始新一批 / 清空当前列表：点击右上角“开始新一批”或“更多 → 清空当前列表（不删除文件）”，确认后将清空当前列表中的全部测点、结果预览与运行日志，以便开展下一批数据处理。上述移除与清空操作均不会删除硬盘上的原始 DAT 文件或已导出的历史 CSV 文件，也不会重置“高级设置”中的参数与自定义分层规则库。

二、测点配置：单点编辑与批量设置
1. 操作入口与作用范围区分：
   • 编辑当前测点（单点配置）：用鼠标单击列表中某一行使其高亮，再点击“编辑当前测点”（或直接双击该行除复选框外的任意单元格），可在弹出窗口中修改该测点的编号、参考水深、分层规则及起止时间。
   • 批量设置（多点统一配置）：勾选测点首列的复选框（可点击“勾选全部 / 取消全选”按钮或表头复选框全选，支持跨行不连续勾选；注意鼠标多行高亮不代替勾选），点击“批量设置”，可统一设置所勾选测点的水深、分层规则和起止时间（不支持批量修改测点编号）。
   • 按项独立生效：在单点或批量编辑窗口中，只有明确勾选启用（如勾选“修改水深”、“修改分层规则”或启用时间限制）的项目，才会在点击“应用”时生效；未勾选启用的项目将严格保留各测点原有的设置与数值精度。若所填内容有误（如水深填为 0、编号冲突、时间未填完整或开始时间晚于结束时间），点击“应用”时窗口会提示具体原因并保留已填内容供修改；点击“取消”或关闭窗口则不保存本次修改。
2. 参考水深（H）设置：
   • 默认自动推算：新导入测点的水深默认留空（显示“处理时自动估算”）。导入文件或保存测点设置时不会立即读取文件计算水深，而是在点击“开始处理并导出 CSV”时由后台结合多段有效下放剖面的深度峰值自动推算。
   • 修改水深方式：在单点或批量编辑窗口中，需先勾选“修改水深”，再从下方两个单选项中选择其一：
     - 手动填写：输入大于 0 的实测水深值（单位：米），处理时将直接采用该人工水深，不会被自动推算覆盖。
     - 处理时自动估算：清除当前已指定的水深，恢复为下次开始处理时由软件自动推算（注意：请勿将手动输入 0 当作自动推算；若需恢复自动推算，请选择“处理时自动估算”单选项，或直接在主表水深单元格中清空数值）。
   • 同一测点在单次处理中采用固定参考水深 H，不随潮位逐时变化。
3. 垂向分层规则选择：
   • 在单点编辑窗口（直接下拉选择）或批量设置窗口（需先勾选“修改分层规则”）中，可为测点指定以下分层方案：
     - 根据水深自动选择（默认）：随测点参考水深 H 自动匹配系统标准层数：
       • 0 < H < 2 米：系统规则 1 层（0.6H）
       • 2 ≤ H < 5 米：系统规则 2 层（0.2H、0.8H）
       • 5 ≤ H < 8 米：系统规则 3 层（0.2H、0.6H、0.8H）
       • 8 ≤ H < 11 米：系统规则 5 层（表层、0.2H、0.6H、0.8H、底层）
       • H ≥ 11 米：系统规则 6 层（表层、0.2H、0.4H、0.6H、0.8H、底层）
       批量恢复为“根据水深自动选择”时，各勾选测点将分别按各自的水深独立确定层数。
     - 固定系统规则（系统规则：1层 / 2层 / 3层 / 5层 / 6层）：下拉列表中带“（默认）”字样的选项仅提示当前水深对应的推荐层数。一旦明确选定某档“系统规则：x层”（即使选中的恰好是当前推荐项），该测点层数即保持固定，后续修改水深 H 时层数不再自动跳变，仅按新水深重新折算各相对层的目标深度；如需恢复随水深自动切换，请重新选回“根据水深自动选择”。
     - 自定义规则：选用已在右上角“高级设置 → 分层规则”中创建的自定义分层方案。
4. 起止时间限定（目标整点范围）：
   • 起止端独立设置：开始时间和结束时间可仅限定其中一端，也可两端同时限定。单点编辑中通过勾选“限定开始时间”、“限定结束时间”分别启用（取消勾选即解除该端限制）；批量设置中，“开始时间操作”与“结束时间操作”均提供“不更改（保留各点原设置）”、“设置时间（统一设为指定时刻）”和“不限定（清除该端限制）”三种操作。
   • 日期与时间填写：凡启用时间限定的一端，均须同时填妥完整的日期（年-月-日）和时间（24小时制 时:分:秒），按仪器记录时间填写，且开始时间不得晚于结束时间。可点击输入框右侧的日历图标（点击日历顶部年月标题可快速切换年份和月份）或时钟图标（滚轮或点击选择时、分、秒后点击“确定”）点选，也可直接用键盘输入。
   • 业务含义说明：起止时间限定的是【本次需要生成哪些目标整点】，而非先把时间范围外的原始观测记录裁剪丢弃；时间窗口外相邻的原始观测仍可正常参与观测片段识别与整点匹配：
     - 未限定开始时间：从首条有效观测所在的小时整点开始（如首条记录为 08:23:00，则首个目标整点为 08:00:00）。
     - 明确限定开始时间：向上取整点（如限定开始为 08:23:00，则首个生成的目标整点为 09:00:00；若填写 08:00:00 则包含 08:00:00）。
     - 未限定结束时间：至最后一条有效观测所在的小时整点结束。
     - 明确限定结束时间：包含不晚于该时刻的整点（如限定结束为 10:30:00，则最后一个目标整点为 10:00:00）。
     因此，若限定 08:23:00 至 10:30:00，软件将生成 09:00:00 和 10:00:00 两个目标整点；若所设时段内不含任何整点，则不会产生结果行。

三、高级设置：自定义分层规则库、筛选参数与 CSV 选项
1. 自定义分层规则管理（“高级设置 → 分层规则”）：
   • 新建规则：点击“创建自定义规则”，填写规则名称（不可为空，且不可与已有规则或系统规则重名），在“层位”框输入 0～1 之间的相对水深比例并点击“添加到列表”，依次添加所需层位（支持 1～64 个不同层位，系统自动去重并按由浅入深排序）。其中：
     - 输入 0 代表“表层”（按表层评分逻辑从深度超过表层下限的浅水观测中选点，并非强行生成 0 米记录）；
     - 输入 1 代表“底层”（取该次匹配观测片段内的最深实测记录，不强制要求等于总水深 H）；
     - 其余数值（如 0.2、0.4）代表目标采样深度为对应比例乘以水深（即 0.2H、0.4H）。
   • 保存与选用方式：在创建窗口点击“确定”后，新规则立即保存至本地规则库（关闭软件后下次启动依然保留，即便随后在高级设置窗口点击“取消”也不会撤销已保存的规则）。但【新建规则不会自动应用到任何测点】，创建后请返回主界面，在“编辑当前测点”或“批量设置”中为需要采用该方案的测点手动选定并点击“应用”。
   • 删除与重命名：选中未使用的自定义规则点击“删除自定义规则”即可立即移除；正在被当前列表中测点使用的规则无法直接删除，请先返回主界面将相关测点切换为其他规则并保存，再打开高级设置删除。若旧规则存在重名冲突，可点击“调整旧规则名称”修改名称（层位保持不变）。
2. 筛选参数与深度容差（“高级设置 → 筛选参数”）：
   • 片段识别参数：
     - 片段断档上限（分钟，默认 5）：相邻有效观测时间间隔超过此值时，划分为不同观测片段。
     - 前缓冲（分钟，默认 8）：将观测片段正式开始前该时间范围内的观测一并纳入候选。
     - 后缓冲上限（分钟，默认 8）：限制片段末尾已纳入的低深度观测保留时长（并非在片段结束后再向后读取未来 8 分钟的数据）。
     - 结束所需连续低值（个，默认 4）：深度下降阶段连续出现达到该数量的低于分段阈值的观测时，结束当前片段。
     - 最低参考深度（米，默认 0.10）：分段深度阈值不低于此值（并非测点参考水深 H）。
   • 整点匹配参数：
     - 整点与片段峰值的最大时间差（分钟，默认 60）：观测片段内最深实测时刻与目标整点的时间差不超过此值（含边界）时，方可与该整点匹配。
   • 表层选择参数：
     - 表层深度下限（米，严格大于，默认 0.5）：表层候选点的实测深度必须严格大于此值。
     - 表层评分权重（深度权重默认 1、距整点时间权重默认 0.1、距片段起点权重默认 0.05）：共同决定表层候选点的综合评分，数值越大越优先选取深度更浅、时间更接近目标整点或更靠近片段起点的观测记录。
   • 质量检查（深度偏差容差）：
     - 支持勾选“启用绝对深度容差”（单位：米）和“启用相对深度容差”（按【当前目标层深度】的百分比计算允许偏差，而非总水深 H 的百分比；例如水深 H=10 米、0.2H 层目标深度为 2 米，设置 10% 容差即允许偏差 0.2 米）。
     - 两者同时启用时按更严格的标准判定（偏差等于上限仍视为通过）。超出容差的采样值不会被自动剔除或修改，仍会正常导出至 CSV，同时在结果页标记“深度超差”供复核。若均未启用，结果详情中将显示“未检查深度偏差是否超限”。
3. CSV 导出选项与生效方式（“高级设置 → CSV导出”）：
   • CSV 编码：默认采用“UTF-8（推荐，Excel可识别）”，也可切换为 GB18030 或 Windows ANSI。
   • 仅导出各层数据齐全的整点：默认不勾选。勾选后，若某一目标整点存在任一层位缺测，该整点将整行不写入导出的 CSV 文件（但不会排除片段复用、跨层复用或深度超差记录；且在软件“处理结果”页中仍可查看包含缺测在内的完整记录）。
   • 点击左下角“恢复当前页默认”可恢复当前标签页的初始值；修改筛选参数或 CSV 选项后，须点击右下角“应用设置”方可生效。

四、开始处理、水深确认与失败重试
1. 保存位置与处理范围：
   • 先在主界面底部确认“CSV 保存位置”（默认位于当前系统用户主目录下的“OBS处理结果”文件夹，可点击“更改”重新选择；为保护原始数据，保存位置不得选在任何输入 DAT 文件所在文件夹或其子文件夹内）。
   • 点击“开始处理并导出 CSV”，软件将对当前列表中的【全部测点】依次进行处理并自动导出 CSV 文件。首列复选框仅用于批量设置和移除，不限定开始处理的范围；若仅需处理部分测点，请先将其余测点移出列表。
2. 水深推算、弹窗核查确认与异常输入隔离：
   • 处理开始时，软件仅对水深留空的测点进行后台推算（已人工填写水深的测点直接采用人工值，不被覆盖）。
   • 若部分测点的数据文件格式正常，但因有效剖面较少、峰值深度波动较大、存在同秒数据冲突或有效观测不足无法推算（显示“请填写”）等原因需要人工把关，将自动弹出“水深填写与确认”窗口，集中列出需核实的测点、建议水深及原因。请在弹窗中逐行填入大于 0 的现场实测水深（不可填 0，也不会借用其他测点水深代填）或核实建议值，勾选右侧“确认”复选框（每行均须勾选），再点击“确认并继续处理”，即可直接接续完成本次处理与导出，无需重新导入文件。
   • 单点输入错误通常按测点隔离处理：若单个测点关联的原始文件无法读取或格式结构损坏，软件不会要求为其填写水深（不可通过填写水深绕过文件校验），而是在正式处理阶段按测点独立报错并记入结果与运行日志，不影响其余正常测点的水深确认与处理导出。但若整批任务的文件总数量、累计容量或处理预算超限，软件可能会停止整批准备或处理，此时请缩小本批处理的测点或文件范围后重试。
   • 在水深确认弹窗中点击“取消”、按 Esc 或关闭窗口，将安全停止本次任务并立即恢复主界面编辑操作，同时保留已有的历史结果。平时也可点击主界面提示按钮或通过“更多 → 查看当前测点水深详情”查阅各点水深推算依据（日常查看窗口为只读模式，修改水深请使用“编辑当前测点”或“批量设置”）。
3. 取消任务与失败重试：
   • 处理或推算水深期间可点击底部“取消任务”安全停止。
   • 若个别测点因文件格式损坏或无有效观测等原因处理失败，不会中断其余合格测点的处理与导出；处理结束后可点击“展开运行日志”查看报错原因，排错后点击“仅重试失败测点”即可单独重跑失败项，其他已成功测点的结果会完整保留。

五、结果核查、过程线浏览与 CSV 文件说明
1. 摘要统计与表格筛选（“处理结果”页）：
   • 处理完成后自动切换至“处理结果”页。顶部摘要中，“完成、失败”按【测点数量】统计，“缺测、需核查”按【目标整点数量】统计。“完成”仅代表程序运算与文件导出结束，请务必结合提示复核数据质量。
   • 先在左上方下拉框选择测点（若修改了测点配置或高级参数但尚未重新处理，界面会保留旧结果并提示“设置已更改，重新处理后生效，当前为上次结果”）。
   • 可按“全部记录 / 缺测记录 / 需核查记录”筛选状态，或按“全部指标 / 深度 / 温度 / 盐度 / 浊度”切换显示列，也可在查找框中输入目标整点时间（如“2026-10-16 09”）快速检索。
   • 结果表支持点击表头排序，选中单行或多行（按住 Ctrl 或 Shift）后按 Ctrl+C 可复制表格内容。筛选、切换指标和排序仅改变界面显示，不改动已导出的 CSV 文件。
2. 状态定义与标红异常复核：
   • 缺测记录（含两类）：
     - 缺少匹配片段：在设定的最大匹配时间差内，未找到可供该目标整点匹配的有效观测片段。
     - 缺层：已匹配到观测片段，但因该片段深度覆盖不足等原因，部分层位未能选到有效观测记录（表格中留空）。
   • 需核查记录（含三类，软件予以保留并提示人工复核，不擅自删改数据）：
     - 片段复用：多个目标整点匹配并共用了同一段有效观测片段。此时结果表中【所有共用该片段的目标整点时间均会标红】（包括首次使用该片段的整点）。
     - 跨层复用：同一整点的不同层位选用了同一条原始观测记录。在“各层采样”表中，相关层位名称、实际深度及温盐浊数值均会标红提示。
     - 深度超差：相对层的实际采样深度与目标深度之差超出了已启用的容差上限。
3. 展开曲线、各层采样与来源详情：
   • 点击右下角“展开曲线与采样详情”（窗口较小时将自动在独立窗口中打开；平时可拖动分隔条调整高度，或通过“更多 → 恢复默认布局”还原），可查看三个标签页：
     - 曲线：展示时间-深度过程线（深度向下递增）。蓝色代表本次匹配的有效观测片段，灰色代表原始观测背景或相邻片段，实心方块（■）代表各层选中的采样点（鼠标悬停可查看详情），实心三角（▲）代表片段最深峰值，竖向虚线代表目标整点与有效数据起止边界。观测时间断档处保持自然断开留白，不作连线或人工插值。支持鼠标滚轮缩放、拖动底部水平滚动条平移，以及点击视图边缘的方向提示按钮或右下角“恢复全图”回到默认视野。
     - 各层采样：逐层列出层位名称、目标深度 (m)、实际深度 (m)、偏差（实际深度减目标深度，单位 m）、实际采样时刻、来源文件名、原始行号以及温度、盐度、浊度数值。
     - 来源详情：详细列出共用片段所关联的全部目标整点与片段实际起止时间，以及跨层共用原始记录所涉及的层位、文件完整路径、原始行号、实际深度和按当次参考水深 H 换算的实际相对水深比例（如 0.400H），并逐层展示每条采样记录的完整来源路径与行号。
4. CSV 文件查阅与软件保存范围：
   • 打开结果文件夹：CSV 文件在处理过程中已自动导出保存。在“处理结果”页左上角下拉框选定测点后，点击“打开结果文件夹”，即可直接打开该测点本次运行对应的输出目录（目录名格式如“OBS处理结果_2026-10-16_0830”，同一分钟内多次运行会自动附加“（2）”等递增序号，绝不覆盖历史结果）。
   • CSV 格式与数值说明：每个成功测点生成一份“<测点编号>#_output.csv”文件。第 1 行为本次采用的输入深度及各层目标深度信息；第 2 行为列名（依次为日期、整点、各层实际深度、逐层温度/盐度/浊度）；第 3 行起每行对应一个目标整点。所有数值均直接取自选中的原始观测记录（保留三位小数，不做平滑、平均或插值；缺测项留空而不填为 0）。
   • 软件重启保留范围：自定义分层规则库、窗口尺寸位置及结果区分隔布局会在关闭软件后自动保存；但当前测点列表、测点参数设置及结果预览在软件关闭后不会保留，下次启动时请重新添加数据文件（已导出的历史 CSV 文件仍保存在输出目录中，可随时用 Excel 等软件打开）。

六、实用工具：DAT 文件时间校正向导
1. 适用场景与启动入口：
   • 当现场施测时 OBS 仪器内部时钟未校准（如停留在初始年份或与标准时间存在偏差），导致 DAT 原始文件中的记录时间整体偏离实际测验时间时，可点击主界面右上角“实用工具”，点击“时间校正”宽栏入口，按四步向导校准单份 DAT 文件的记录时间。
   • 主界面正在处理数据时无法启动实用工具；时间校正任务运行期间也无法同时启动主界面批量处理。
2. 四步校准操作流程：
   • 第 1 步（选择文件）：
     - 点击“选择DAT文件”选定一份需要校准的 DAT 文件（每次仅校准一份文件）。软件在后台完成只读检查后，会显示有效观测条数、原始记录时段及已识别传感器列，确认后点击“下一步”。
     - 在同一向导会话中，若重新选择同一份或其他 DAT 文件，软件会保留此前已填写的“实际正确时间”、测验起止整点及校正方式草稿，并重新读取当前文件的仪器参考时间；但原有的分析预览、首尾缺测分配、另存目标及保存许可均会立即清除，请务必核对所保留的草稿设置是否适用于当前文件（若取消或关闭工具后重新进入时间校正，则开启全新会话并清空全部草稿）。
   • 第 2 步（设置校正方式）：在下拉框中选择两种校准方案之一：
     - 已知时间对应关系：填写同一采样时刻对应的“仪器记录时间”（默认预填文件首条有效观测时间，可按实际对表时刻修改）与“实际正确时间”（精确到秒）。软件将按二者的固定时差整体平移整份文件的有效观测时间，采样间隔与各传感器数值保持不变。
     - 按抛测规律匹配：填写实际测验的“测验开始整点”与“测验结束整点”。此模式采用整点专用输入控件，日期包含完整年份，时间框仅需输入 0—23 的小时数，右侧固定显示“:00:00”（时间选择浮层中的分、秒亦固定为 00 且不可修改；不支持粘贴非整点时间，也不会自动将非整点截断归整）。
     - 候选片段整理与抛测动作识别说明：在“按抛测规律匹配”模式下，软件不会简单把所有局部水深波动都当作独立抛测，而是先按持续浅水停留或真实时间断档划分观测过程并分别计算进入阈值（避免深水抛测掩盖浅水抛测），再将连续近邻、中途回撤未超过前峰水深一半，或仅夹杂 1～2 条短暂浅水记录（耗时符合周围正常采样节奏且迅速回到原水深范围）的候选片段合并为一次完整的“抛测动作”，并以每次抛测动作的最深实测时刻（等深时取较早记录）作为锚点对齐目标整点序列（要求相邻抛测动作间隔距整数小时偏差、以及平移后锚点距目标整点残差均不超过 15 分钟，含边界）。
   • 第 3 步（核对结果）：
     - 首尾缺测分配：在“按抛测规律匹配”模式下，若除中间时段断档缺测外，测验开头或结尾仍存在缺测，曲线上方会显示“开头缺测次数”与“结尾缺测次数”输入框（两者之和须等于剩余缺测次数），请填妥后点击“确认首尾缺测并重新预览”；若确实无法回忆具体位置，可点击“不记得，按开头无缺测处理”。确认后仍可点击“修改缺测分配”重新调整。
     - 曲线符号与全图浏览：核对上方原始/校正后时间范围与平移秒数摘要，并通过下方深度-时间预览曲线核查。曲线中【空心圆（○）】代表识别出的原始候选片段峰值，【实心方块（■）】代表整理合并后的每次抛测动作最深锚点。预览曲线的最大浏览范围与“恢复全图”会同时覆盖有效观测时段与全部目标整点（包含开头或结尾缺测的目标整点）并预留边缘空白。
     - 展开对应明细与原始时刻区分：点击“展开对应明细”，在上方匹配表格中单击任意目标整点行，曲线视野会自动平移定位至该目标整点（保持当前缩放比例并同步滚动条）；表格下方还会详细列出每个抛测动作所含的候选片段编号、最深观测时刻与深度、来源文件路径与行号、合并依据，以及各候选片段的起止时间与分界不确定说明。注意：【预览曲线显示的是按时差统一平移后的时间，而对应明细表与下方来源说明中列出的代表时刻、候选起止时刻均为文件中的仪器原始记录时间】。
     - 异常与分界不确定拦截：若文件内部存在时间倒退/多次重置、格式错误，或抛测匹配下相邻候选片段之间回撤较深且缺乏明确浅水停留分界、短暂浅值耗时超出正常采样节奏、近邻动作对应同一目标整点导致“抛测分界不确定”，抑或异常整点达到总整点数一半及以上、动作间隔紊乱、动作次数超出测验范围，软件仅展示过程线与明细供人工核查，同时禁用“下一步”，不允许修改文件。确认预览无误后点击“下一步”。
   • 第 4 步（确认修改与自动备份）：
     - 前 3 步及中途点击“取消”均为只读预览，不会改动任何文件。进入第 4 步后，请仔细核对源文件路径、时间平移摘要及“将直接修改原始 DAT 文件”提示。
     - 为防止连击误触，进入本页后“确认修改”按钮会短暂延迟启用，且按回车键不会触发保存，必须用鼠标主动点击“确认修改”才会正式写入。写入时，软件会先在原文件同目录下创建一份完整的原始备份文件（名为“原文件名.dat.bak”，若已有备份则自动递增为“.bak.1”、“.bak.2”，绝不覆盖旧备份），校验无误后再更新原文件中的观测时间（表头、传感器数值与仪器尾注均原样保留）。
     - 若原文件因被占用、无写入权限或磁盘空间不足导致原位保存失败，界面会停留在第 4 步并显示“选择保存位置后重试”按钮，可点击指定一个新的 .dat 文件名另存（不得覆盖已有文件），返回第 4 步核对新路径后再次点击“确认修改”即可完成另存（另存模式下原文件未改动，不额外创建 .bak 备份）。
   • 校正完成与后续处理：保存成功后进入完成页，展示输出文件路径与备份路径。若原位校准的 DAT 文件已包含在主界面测点列表中，请返回主界面重新点击“开始处理并导出 CSV”，以基于校准后的正确时间生成新的 CSV 表格（若采用另存方式生成了新文件，请先在主界面通过“设置数据文件”关联新文件后再处理）。
